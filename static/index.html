请求头

        

          
Header说明

          
AuthorizationBearer <token> —— 登录后携带，服务端据此确定密级（唯一可信来源）

          
X-User-Clearance
              已废弃。登录态下该头被忽略；仅未登录的本地调试模式生效。保留它是因为客户端可随意伪造，存在越权风险。

          
X-User-Tenant
              已废弃，租户同样取自 token。

          
X-API-Key保留但未实现真实校验

        

      

      

        
已知契约缺口（前端已绕行，建议后端补齐）

        

          
缺口影响 / 绕行方式

          
QAResponse 无 query_log_id反馈无法直接关联问答。前端绕行：回答后调 /query-logs?limit=1 取最新一条并校验问题文本；并发时会错配，建议后端在 QAResponse 增加该字段。

          
QAResponse 无链路诊断字段cache_hit / degraded / llm_used 已写进 query_logs 但不返回给前端，需二次查询才能展示。

          
SourceItem 仅有 score分数是 RRF 融合值，无法区分 dense / sparse 贡献，排查检索问题时信息不足。建议增加 dense_score / sparse_score。

          
缺少删除文档接口文档页只能查看，无法下线文档（后端 Document 有软删除字段但未暴露）。

        

      

      

        
访问方式

        

          本页依赖跨域访问后端。若后端未挂载静态目录，可用任意静态服务器打开：

          
          python -m http.server 8080 --directory static

          然后访问 http://localhost:8080/index.html。或在 FastAPI 中挂载（见交付说明）。
